# RepairPOS Website Instructions

- Keep all new pages and changes consistent with the existing website style, including colours, typography, spacing, buttons, cards and responsive layouts.
- Use the existing Bootstrap 5.2.3 framework, grid, components and utility classes. Do not introduce another CSS framework or change the Bootstrap version unless explicitly requested.
- Reuse `partials/head.php`, `partials/header.php`, `partials/footer.php` and the existing styles in `css/styles.css` wherever applicable.
- Follow the structure and conventions of existing website pages. Keep any additional CSS minimal and consistent with the current design.
